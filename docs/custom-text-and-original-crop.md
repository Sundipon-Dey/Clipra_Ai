# Custom text and Original Layout crop

The clip editor's right panel has separate **Custom Text** and **Local Captions** tabs. Custom Text is an independent overlay; it does not create or edit transcript words. It can use the caption style presets, and has its own position, size, text color, optional stroke, and configurable shadow blur, color, and offsets. Reset stroke & shadow returns those effects to CLIPRA's preferred defaults. Custom text is saved with the editable clip and included in the Chromium-rendered export overlay so the browser preview and export share the same styling component.

In Original Layout, choose Fit / Original, Blurred Background, or Manual Crop. The former Smart Crop and Gemini recommendation controls are not offered in this layout. Legacy drafts saved with Smart Crop open in Manual Crop mode; their saved manual focus and zoom values remain available. The **Trim top and bottom** control removes the selected percentage from each vertical edge before the chosen Original Layout framing is applied. It does not alter split-screen section framing.

The crop percentage and custom text configuration are stored with the clip. Export snapshots capture those values, so later editor changes do not change an already-created export.
